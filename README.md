# Интернет-магазин мебели

Веб-приложение для просмотра каталога мебели, расчета стоимости заказов и онлайн-оформления покупок.

## Функционал

* Каталог товаров с фильтрацией
* Корзина и расчет стоимости доставки
* Личный кабинет покупателя и модуль уведомлений

## Лицензия и условия использования (Freeware / Nagware)

Программное обеспечение магазина распространяется по бесплатной проприетарной лицензии (**Freeware / Nagware**)[cite: 6].

* **Использование:** Бесплатно для всех покупателей и клиентов магазина[cite: 6].
* **Особенности (Nagware):** Система включает регулярные всплывающие уведомления с предложением зарегистрироваться в программе лояльности или получить скидочный купон[cite: 6].
* **Ограничения:** Копирование исходного кода, декомпиляция скриптов и парсинг базы данных товаров запрещены[cite: 6].
